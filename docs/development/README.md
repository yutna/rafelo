# Development documentation

This directory holds instructions for maintainers of the Rafelo template. It is
not copied into applications created from the template.

- [Implementation protocol](implementation-protocol.md) — the operating
  contract for the person or agent converting the template. Re-read it after a
  context compaction.
- [Spec provenance](spec-provenance.md) — where the read-only specification
  copies came from and how to verify them.

The application template's payload lives outside this directory. Maintainer
material may mention repository settings, release steps and local tooling that
an adopted application does not receive.
